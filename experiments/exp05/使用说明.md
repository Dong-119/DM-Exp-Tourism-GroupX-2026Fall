# 实验五 条件性游览建议的抽取

本实验使用实验一输出的48篇结构化文章，从故宫、颐和园和天坛的攻略与游记中提取条件及对应行动，整理适用地点和来源，并按游客类型、条件类型统计。

## 运行

使用Python 3.10及以上，在本目录执行：

```powershell
python -m pip install -r requirements.txt
python run_experiment.py
python verify.py
```

`run_experiment.py`读取结构化正文、分句、抽取候选，结合人工校验数据生成映射表、统计、图表及规则对照。只需JSON、CSV和结果页面时，可执行 `python run_experiment.py --no-plots`，核心处理仅使用标准库。Notebook可从上到下执行，展示同一套函数及输出。

## 数据与处理

`data/clean_documents.json`直接取自实验一“格式化数据/result.zip”中的同名文件。程序以 `clean_content` 为正文基准，保留其字符和段落；`text`是同一正文的兼容字段，不重复读取。文章清洗与文档去重由实验一完成，实验五从48篇独立文章开始，按原文切分得到1406个句段。条件、建议和证据的位置均针对这份正文，使用从0开始、左闭右开的字符区间。

输入包括原语料游记15篇、路线整理稿15篇、教学模拟15篇、官方路线事实重述3篇。来源性质、链接及合并记录保留在输入数据中，不同来源分别统计。

最终映射表已完成人工复核。`data/人工校验.json`保存26项候选排除或修正，以及32条结合原文整理的补充关系，程序据此生成映射表。`data/规则对照样例.json`含21个正例、9个负例，供基础规则与改进规则对照。

## 代码与结果

| 文件 | 内容 |
|---|---|
| `corpus_io.py` | 读取实验一正文、字段对应与分句 |
| `extract_rules.py` | 条件逻辑、候选抽取与建议级去重 |
| `experiment.py` | 原文定位、人工校验、映射表与分类统计 |
| `baseline_rules.py`、`evaluate_rules.py` | 基础规则及30个样例的对照 |
| `figures.py`、`result_page.py` | 图表和原句查看页面 |
| `verify.py` | 输入一致性、原句位置、统计及关键规则检查 |

90条规则候选中接受64条、修正9条、排除17条；结合补充关系后形成95条主体建议和10条其他地点建议。

| 结果文件 | 内容 |
|---|---|
| `results/分句语料.json` | 实验一正文及其句段、字符位置 |
| `results/规则候选.json` | 自动抽取的90条候选 |
| `results/条件建议映射表.json`及CSV | 95条主体建议，供后续图谱使用 |
| `results/范围外建议.json` | 10条其他地点建议 |
| `results/统计结果.json`、`规则对照结果.json` | 分类计数与样例对照 |
| `results/映射表.html` | 按来源筛选建议并查看原句 |
| `results/*.png`及`*.svg` | 四张图及可编辑矢量版本 |

主体按建议组计数；游客类型允许多标签，来源景区与实际适用地点分别记录。建议级去重保留否定、数字、必要条件与例外条件的区别。30个设计样例采用三个景区的同组句式，供比较特定结构的识别和边界处理。
